# Upstream audit — before changes
Source: muellerberndt/mochi commit 39dbb4c675d65316e9323bc1c1648b1810658590.

Plain ES modules, canvas renderer, Python host under Pyodide; no framework or auth/database.
World owns hunger/thirst/fatigue/boredom/lonely, body movement, sleeping, toys, sound,
furniture, local senses, relief/suffering reward. The original 223 senses and 17 motor
outputs feed one Brain.compose association region (512). Life owns feedback credit,
refusals, eligibility, working trace, associative stores, teaching, save continuation.
BrainLink is one serial worker per pack. IndexedDB saves room/page/brain as one life,
with a backup and file import/export. Pack sources are immutable compatibility boundaries.
MIT room/host/viewer; shipped Cadence 0.74.0 wheel GPL-3.0.

Original implementation preserved at /classic.html, original pack unchanged. Extension
adds senses/actions in a new pack, using original trained neurons/edges and expanded
associative stores. Structural migration clears transient eligibility and working state;
old saved lives remain usable in the classic room. Trading credit must never be applied
to the intervening pet action; interval outcomes use the existing associative memory's
explicit observation/action mask, while immediate outcomes can join the next life tick.
