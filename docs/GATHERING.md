# Gathering

## Adventure milestone — 2026-10-05

Fishing requires an owned rod and woodcutting an owned axe. Click a lake node or harvest tree, approach it, then start the timed action. The server reserves shared node availability and checks level, location, room instance, time and ownership. Movement during the channel cancels eligibility. Completion grants weighted server-selected fish or wood and XP exactly once in a transaction. Pending actions can be resumed or cancelled after reload. Minnow, carp, moonfish and koi have differing rarity; softwood, hardwood and bark have differing node requirements. Decorative Town trees cannot be harvested.
