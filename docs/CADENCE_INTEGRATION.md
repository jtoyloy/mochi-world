# Cadence integration in the social world

The existing one-wide-region Brain.compose, coupled settlement, residual/refusal contracts,
crediting of the actually executed action, original senses/body simulation and immutable packs
remain unchanged. Python and published pack files were not altered in this social-world pass.
The measured controls and failed arms remain in STATUS.md.

Each Mochi owns a unique versioned Life/checkpoint. BrainRepository retains atomic file writes,
metadata CAS, account/brain locks and renewable browser-room leases. One serial native host
loads/steps/saves pets, never one process per pet. An open original room temporarily owns the
same brain and pauses scheduled trading. Leaving the normal Phaser world does not delete it.

The original paper scheduler still chooses actual motor actions and applies external risk rules,
then saves observations, outcomes and checkpoints. UI frames, socket movement and LLM text
never choose trades or inject rewards. Companion visual follow/roam is explicitly deterministic.
New nearby-Mochi neural observations/actions are deferred: adding an unmeasured action space
would conflict with the simpler brain/control requirement. Co-presence preferences/relationships
are game records, not evidence of learned neural social competence.

Production public competitions still require checkpoint/training provenance. Browser-owned
training remains a known integrity gap. No new profit or learned-social-performance claim is made.
