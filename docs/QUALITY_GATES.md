# Immutable release quality gates

All evidence identifies source SHA, date, environment, procedure, failures/skips and limitations. FUNCTIONAL is not PRODUCTION_READY. An unrun gate is OPEN, never PASS. No shortened safety-stopped soak, fixture-only screenshot, synthetic crowd or confidence interval crossing zero is a release certificate.

- Full JavaScript and Python suites: zero failures and zero skips with dedicated PostgreSQL and native Cadence. Count movement/animation separately without double-counting totals. Asset validator, production build, diff/hygiene and hosted CI all pass at the candidate.
- Adventure: complete authoritative tick-submission-to-motor p95 ≤1400ms, no missed motors, stale execution or lost/duplicate credit in repeated realistic mixed workload at 150 CCU. Room ordering, enemy-stage ordering and durable exactly-once settlement remain invariant. Direct worker latency alone cannot pass this gate.
- Capacity: 150 real accounts/companions, ≥30 minutes plus ≥2-hour soak on intended hardware, realistic movement/transitions/reconnect/combat/gather/vendor/social/persistence/checkpoint GC, PostgreSQL, TLS and WAN conditions. Zero unexpected disconnects, ghosts, duplicate grants or correctness errors; bounded queues/RSS/storage, documented CPU and bandwidth. Keep the existing 3GiB safety floor. Current status NOT CERTIFIED.
- Storage: measured warm lives, four-version temporary peak, keepRecent=3 demonstrated physical GC plateau; provision conservative 40MiB/life plus database/backups/logs and ≥3GiB free floor (150-pet checkpoint planning alone >26GiB). Backup/restore tests recover both DB and file checkpoints.
- Cadence: frozen held-out random/published/reference controls, predeclared arms, paired uncertainty, ≥5pp gain with interval excluding zero, meaningful pet contribution, obstacle/species transfer and preservation tests before promotion. Current NO PROMOTION; failures remain recorded.
- Client: sustained ≥55 FPS and frame p95 ≤25ms at declared desktop target in 20-player/20-pet scenes; 40-crowd target ≥30 FPS/p95 ≤40ms. ≥10-minute live samples, CPU/heap/unique texture/cache and network measurements. Physical phone performance is a separate unpassed gate; responsive desktop emulation cannot certify mobile support.
- Visual: every required state PRODUCTION_READY after asset and independent browser inspection, no blanks/crops, stable pivots/contact, coherent authored directions, equipment layering, readable maps/UI and bounded memory. Mirrored/reused provisional poses stay provisional.
- Security/economy: independent critical/high findings fixed and re-reviewed, production account authentication/session revocation, HTTP/socket ownership/rate/CSRF, no client reward authority, wallet proof/replay/expiry/idempotency/backing tests. No unfunded claims or treasury execution in application workers.
- Playtest: recorded new/returning/combat/gathering/social/trading/failure journeys and desktop/responsive keyboard/focus/error acceptance on exact candidate. Deterministic tests supplement actual browser journeys.
- Operations: reproducible release build/migrations, TLS/socket proxy, explicit retention/workers, alerts, graceful shutdown/restart recovery, staging smoke, demonstrated backup restoration and production hardware plan.

Budget changes require a documented substantive product decision with preserved prior evidence; they cannot be lowered to make a failed result pass. Final engineering, player experience, visual and operations reviews are independent of implementers.
