# Resource Economy

## Adventure milestone — 2026-10-05

Neri buys fish and Alder buys wood in southern Town. Players choose quantity or all owned stock. A sale atomically removes resources, appends a reward accrual and reserves a treasury liability. Server prices, daily account/global limits, account age, proximity, request identity and cooldowns determine eligibility. Insufficient backing leaves inventory intact. Development prices/caps are mock configuration only, not approved production economics. Gathering remains useful for XP and introductory quests even when token rewards are paused.
